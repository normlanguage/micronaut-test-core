# micronaut-test-core sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies test bean replacement and context options. The runnable scenario is owned by [micronaut-test](https://github.com/normlanguage/micronaut-test/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/test/core/module.norm).
